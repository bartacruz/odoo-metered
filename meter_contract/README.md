# Odoo Metered Contract Integration

This module bridges the gap between meter readings and recurring billing. It extends Odoo's contract functionality to automate invoicing based on actual usage.

## Features

- Meter-to-Contract Link: Easily associate one or multiple meters with a specific customer contract.
- Automated Variable Lines: When a meter is linked, the module automatically generates a contract line with a variable quantity.
- Consumption-Based Invoicing: Invoices are automatically calculated using the latest meter reading, ensuring accurate "pay-as-you-go" billing for utility services.
